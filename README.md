# 🎄 Advent of Code 2024 — Multi-Language Solutions

This repository contains my personal solutions to **Advent of Code 2024**, with a deliberate focus on **solving each day using a different programming language**.

The objective is not only to complete the puzzles, but to **explore multiple programming paradigms, language ecosystems, and problem-solving approaches**, documenting the learning process throughout the event.

---

## 🧠 About Advent of Code

[Advent of Code](https://adventofcode.com/2024) is an annual programming challenge that runs from **December 1st to December 25th**.  
Each day features a new puzzle composed of **two parts**, with increasing difficulty.

The challenges emphasize:
- Algorithmic thinking  
- Data structures  
- Parsing and input handling  
- Optimization and reasoning  
- Creative and unconventional solutions  

---

## 🗂️ Repository Structure

Each directory corresponds to a **single day** of the challenge.

Inside each day’s folder you will typically find:

- `input.txt`  
  The personal input provided by the Advent of Code website.

- Solution files for **Part 1** and **Part 2**  
  Named using a consistent convention (e.g. `Day9_1.c`, `Day10_2.hs`).

- The **file extension indicates the programming language** used for that day.

This structure keeps solutions isolated, reproducible, and easy to navigate.

## 🏁 How to Run the Solutions

Each solution is designed to be run locally using the standard toolchain of its language.

General workflow:
1. Enter the day’s directory
2. Compile or run the solution file
3. Redirect `input.txt` as standard input when required

Language-specific instructions are usually included directly in the source files or are self-explanatory based on the file extension.
